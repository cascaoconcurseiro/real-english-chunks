## Regra central

Uma tela bonita não é um produto concluído. Toda funcionalidade apresentada ao usuário deve possuir dados reais, persistência, estados de interação, regras de negócio, tratamento de erros, acessibilidade, segurança, testes e critérios verificáveis de conclusão.

## Segurança e privacidade

Esta documentação não contém tokens, credenciais, conteúdo do banco de produção, dados de revisão de usuários ou instruções internas da plataforma de hospedagem.
